## Мета

Вивчити особливості мови розмітки HTML5; навчитися створювати таблиці для
відображення структурованих даних і форми для введення та передачі даних
користувача; набути практичних навичок додавання таблиць і форм до структури
типової вебсторінки (лендінгу).

## Що додано до проєкту №1

Репозиторій `hw-02` містить усі файли попередньої роботи (`hw-01`) плюс:

- **Форма заявки** у секції «Контакти»: ім'я, пошта, телефон, повідомлення,
  кнопка відправлення;
- **Форма підписки** на нові обсмажки у підвалі сторінки;
- **Стильовий файл `styles.css`** — оформлення сторінки та форм (поля,
  підказки, фокус, кнопки, адаптивність).

## Критерії 11–16 (форми) — де виконано

| #   | Критерій                                      | Де виконано                                                                                           |
| --- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 11  | Розмітка форми заявки / підписки              | `<form class="order-form">` у `<section id="contacts">`, `<form class="subscribe-form">` у `<footer>` |
| 12  | У всіх інпутів заданий `name`                 | `customer_name`, `customer_email`, `customer_phone`, `customer_message`, `subscribe_email`            |
| 13  | Значення `name` описові                       | Назви точно характеризують призначення поля                                                           |
| 14  | У всіх інпутів є пов'язаний `<label>`         | `<label for="…">` + відповідний `id` у кожного поля                                                   |
| 15  | `placeholder`, якщо в макеті є текст-підказка | `Напр., Григорій`, `you@example.com`, `+380 (__ ) ___-__-__`, `Яку каву хочете замовити?`             |
| 16  | Кнопкам «відправлення» — `type="submit"`      | `<button type="submit">Надіслати заявку</button>`, `<button type="submit">Підписатися</button>`       |
